Add Watches to Folio's Variables window. While browsing, an author adds expressions, each run in the default context or a chosen loaded Script, as the Message Box does. Watches are evaluated only while Play is paused: on pausing, after each Step and Message Box line, and when one is added. Running Play spends nothing on them. A Watch shows its value, "(waiting)" or its error, and warns when it sent a message. Watches stay across Play Sessions of the same Project (#1210).
