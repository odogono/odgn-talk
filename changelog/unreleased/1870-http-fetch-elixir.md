Let Scripts make HTTP requests with `http`'s `fetch` in the Elixir Host. `NorthTalk.HTTP.capability/1` defines `http` with `fetch`, which the Zig Core checks as a Standard factory. Its `:origins` binding allows none by default, any, a list of exact origins, or what a function of the Grant's binding gives. Its HTTP/1.1 and HTTPS client follows no redirect, decompresses nothing, skips informational responses, bounds the response, verifies certificates and host names, and closes the connection of an abandoned call (#1870).
