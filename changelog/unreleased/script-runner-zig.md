Run a Script file with the native Zig `northtalk app.talk [args…]`, the renamed `talk-repl`: it grants console, clock, timer, an in-memory store, http and, at a terminal, user as used, Delivers `start args`, serves `http` through a native router with `--port` or `PORT`, exits when nothing can happen again and stops gracefully on SIGINT or SIGTERM. With no file it is the REPL, as before (ADR 0126).
