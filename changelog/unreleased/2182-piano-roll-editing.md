Edit Mini-Notation in Folio's Piano Roll: select a note, linked to the Code Browser's selection, move it with ↑↓ (Shift for an octave) or by dragging, press Delete for a rest, S to split it and M to merge it back, and click a rest's cell to write a note there. Each edit rewrites only that step's text, and anything that would change the brackets is refused (#2182).
