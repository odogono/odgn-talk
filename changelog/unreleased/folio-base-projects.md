Start a Folio Project from Blank or from Music with the File menu's **New Blank Project** and **New Music Project**. Music brings every kit sound as the Project's own, plus a `bass` synth, and is fetched the first time it's used, then kept for offline use. A Project records the Base Project and version it was copied from, so the `.folio` format is now 8.
