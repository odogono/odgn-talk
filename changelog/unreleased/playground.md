Add the NorthTalk Playground, the REPL's browser counterpart. It has a Script tab
that Apply enters into the session, Library tabs, the language server, formatter and
Lints in a worker, live and replay debugging, and Shared Links that replay a Session
Transcript on opening. Run it with `bun run playground`. A browser corpus page runs
the Trace Cases and Session Transcripts on the TS Core in a browser.
