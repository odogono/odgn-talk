Folio's Message Box is now a code window like a Script's: it resizes from its corner and offers the same completion (⌃Space), hover and diagnostics for the Page's names. HyperTalk-style `hide` and `show` commands, such as `hide welcomeText`, work in the Message Box and in any Script that writes `use hide, show from folio`. Every Folio window, including Tools and Info, now has the same title bar with a close box, Info resizes like Script windows, and a new **Window** menu shows and hides Tools, Info, the Message Box and Errors; the Message Box moves there from the Edit menu.
