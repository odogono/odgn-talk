Folio's Message Box is now a code window like a Script's: it resizes from its corner and offers the same completion (⌃Space), hover and diagnostics for the Page's names. HyperTalk-style `hide` and `show` commands, such as `hide welcomeText`, work in the Message Box and in any Script that writes `use hide, show from folio`.
