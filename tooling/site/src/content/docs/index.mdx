## A taste

Handlers answer messages. Clauses pick one by the shape of the argument, and
`wait` is the only place a Run can pause.

```talk
on handle {type: "invoice", amount: a} as inv where a > 1000
  send review with inv to approvals into verdict and wait
  if verdict is "approved" then file inv
end handle

on handle {type: "invoice"} as inv
  file inv
end handle

on handle other
  pass handle                       -- hand it on up the Message Path
end handle
```
