# NorthTalk for VS Code and Cursor

Editor support for `.talk` files: syntax highlighting, bracket and comment
handling, and the [NorthTalk language server](../cli/README.md#language-server)
(diagnostics and Lints, completion, hover, go to definition, references,
rename, formatting, quick fixes and suspension inlay hints). None of it is
normative ([ADR 0028](../../docs/adr/0028-tooling-is-one-ts-stack-and-nothing-it-produces-is-normative.md)).

## Install

From a clean checkout, with Bun 1.4.2:

```sh
bun install
bun run --cwd tooling/vscode package     # writes tooling/vscode/dist/northtalk.vsix
code --install-extension tooling/vscode/dist/northtalk.vsix
cursor --install-extension tooling/vscode/dist/northtalk.vsix
```

Or run **Extensions: Install from VSIX…** in either editor. The package bundles
the language server, so it needs no checkout, Bun or Node once installed.

## Settings

- `northtalk.profile`: the Lint profile, `standard` (default) or `beginner`.
- `northtalk.manifest`: a Host Manifest path, relative to the first workspace
  folder. Empty selects the single `*.talk-manifest.json` in the workspace roots.
- `northtalk.server.runtime`: the runtime that runs the server, such as `node`
  or `bun`. Empty uses the editor's own Node.
- `northtalk.server.path`: a `northtalk` CLI script to run in place of the
  bundled server. To use a checkout's source directly, set the runtime to `bun`
  and the path to its absolute `tooling/cli/src/main.ts`.

Changing a `northtalk.server` setting restarts the server; **NorthTalk: Restart
Language Server** does so on demand. **NorthTalk: Show Dictionary** opens the
Host Manifest's Grants and their Operations, with how each is called, as a
Markdown document beside the editor. Enable `editor.inlayHints.enabled` to see
suspension marks.

## Development

- **Highlighting** is a TextMate grammar,
  [`syntaxes/northtalk.tmLanguage.json`](syntaxes/northtalk.tmLanguage.json),
  generated by [`tools/grammar.ts`](tools/grammar.ts) from the Core's Reserved
  Words, FOLLOW set and Unit names and from the Built-ins in
  [`stdlib.toml`](../../spec/data/stdlib.toml). Edit the generator, then run
  `bun run --cwd tooling/vscode grammar:generate`. Contextual words are
  coloured as keywords wherever they stand, as in the Playground; Argument
  Labels are not distinguished.
- **The client** is [`src/extension.ts`](src/extension.ts). It launches
  `northtalk lsp` over stdio and passes `profile` and `manifest` as
  initialization options and configuration.
- **Build:** `bun run --cwd tooling/vscode build` bundles the client and the CLI
  into `dist/`. To debug, open this directory in VS Code and run the Extension
  Development Host with `dist/` built.
- **Tests:** `bun test tooling/vscode/tests` tokenizes examples with
  `vscode-textmate` and checks the grammar is current.
