
- Settled by #69: `text` gains `format(template, values)`, the language's only interpolation. `{name}` shows the value of that key of `values` in its canonical text form, and `{{` and `}}` are literal braces, as in `date`'s templates (ADR 0023). There is no width or precision spec, since `pad` and `round` do that. A name that isn't a key, or an unclosed brace, raises `out of domain` with `{function, value}`. A template whose names are keys can be translated with its words reordered, which `&` chains can't.
