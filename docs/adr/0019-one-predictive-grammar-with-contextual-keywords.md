
- Settled by #69: a bare `return` ends a Handler or function early, giving Nothing, as reaching `end` does. `exit` only ever takes `repeat`, and there is no `exit <handler>` or `exit to …`. Unwinding a whole Run is `throw`. `the number of m` stays key access, so there is no `the number of words in s` (it would need four tokens to decide): Scripts write `the length of the words of s`.
