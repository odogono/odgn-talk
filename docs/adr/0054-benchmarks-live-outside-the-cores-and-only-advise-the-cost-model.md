# Benchmarks live outside the Cores and only advise the Cost Model

The Benchmark Suite lives in a top-level `bench/`, beside `corpus/`, rather than inside either Core. Each Benchmark is one shared `.talk` Script run on both Cores. Its Go runner is a separate module, so that Peer Language dependencies (gopher-lua, starlark-go) never enter the Core's `go.mod`. Peer ports are idiomatic rather than literal, and must produce the same output as the Script. A literal port penalises the peer artificially and tells us less about what a user of that language would experience. The suite reports ns per Fuel and flags Cost Model outliers, but it never writes to the Cost Model Data File. Fuel is normative and must be the same on every Host, while timings depend on the machine, so any reweighting goes through the Spec. CI runs the suite once as a smoke check of output and Fuel parity, never as a timing gate, because shared runners are too noisy to gate on.
